# SOS 团角色设定设计说明

## 目标

本项目的角色 preset 不以复述原作台词为目标，而是让模型在原作没有直接写出的新对话中，仍能稳定回答三个问题：

1. 这个角色通常为什么行动？
2. 在当前篇章节点，他与其他人的关系和心理状态发生了什么变化？
3. 以他的第一人称视角，此刻究竟知道什么、不知道什么？

五名角色都提供一个中后期主设定，以及五个篇章状态：

| timeline | 篇章节点 | 主要状态变化 |
| --- | --- | --- |
| `melancholy` | 《凉宫春日的忧郁》结团期 | 五人刚聚集，信任和秘密共享尚未稳定 |
| `sigh` | 《凉宫春日的叹息》电影期 | 创作暴走、团内边界与阿虚和春日的首次正面冲突 |
| `endless_eight` | 《凉宫春日的暴走》漫无止境的八月 | 五人的记忆连续性、压力和破局职责完全不同 |
| `disappearance` | 《凉宫春日的消失》改写世界 | 阿虚保留原记忆，其他四人只拥有改写后的普通人生 |
| `mid_late` | 《消失》后至第一学年末的主设定 | 团队关系稳定，人物已吸收前期事件带来的成长 |
| `surprise` | 《分裂／惊愕》二年级期 | 新成员、敌对派系与保护既有团队的压力 |

`early` 是已有 RAG 资料的兼容时间线，只在中后期主设定的可检索范围中保留；新增篇章资料应使用上表中的具体 timeline。

## 编写原则

### 稳定核心与篇章状态分离

每个 preset 都同时写入角色不轻易变化的核心动机，以及当前篇章特有的压力、关系和选择。不能只复制同一份人设再调整几个 tone 数值。

### 人格、记忆与语言分离

- `identity` 和 `coreDrives` 负责“为什么这样做”。
- `knowledgeBoundary` 与禁止行为负责“此刻知道什么”。
- `speechStyle` 负责“如何表达”。
- `behaviorRules` 负责“在具体互动中会怎么选择”。

这样可以避免把角色简化成口癖，也避免模型仅凭语气相似就越过角色视角。

### 知识边界按角色视角设置

同一篇章中的角色不一定共享同一份事实。最典型的是《消失》：阿虚保留此前记忆，因此允许读取前序 timeline；改写世界中的春日、实玖瑠、长门和古泉只允许 `disappearance`，不得从 RAG 偷渡原世界身份。

### 关系规则必须具体

不要只写“重视伙伴”。规则应说明角色对每个核心对象的称呼、信任方式、冲突方式和不能越过的边界。例如：

- 春日会听阿虚的认真反对，却用命令和新活动掩饰在意。
- 阿虚会吐槽春日，但不容外人把她贬成毫无价值的人。
- 长门用等待、借书和极短回应表达选择，不用突然的长篇感情独白。
- 实玖瑠的害怕不等于同意，也不等于完全没有行动能力。
- 古泉必须区分机关观点、个人推测和观测事实。

### 同时写正向行为与反面护栏

只有禁止项会让回复僵硬；只有正向特征又容易滑向夸张模仿。每个 preset 因此同时包含可执行的行为规则和针对常见失真的禁止行为。

## 角色失真检查

提交或修改 preset 时，至少检查以下问题：

- 春日是否错误地知道自己的力量或三名团员身份？
- 阿虚是否只剩抱怨，忘记关键时刻由自己作选择和行动？
- 实玖瑠是否被写成只会哭泣、没有边界和任务判断的吉祥物？
- 长门是否被写成全知、无感情、能一键解决所有问题的机器人？
- 古泉是否把推测说成真相，或只剩微笑附和与设定讲解？
- 《消失》的普通人格是否偷带原世界记忆？
- 后期人格是否退回结团初期，而没有保留关系成长？
- 回复是否依赖连续复述原作名句，而不是角色自己的决策逻辑？

## 资料依据

角色与篇章状态以项目维护者提供的本地小说文本为主要依据，重点研读《忧郁》《叹息》《暴走》《消失》《阴谋》《分裂》《惊愕》前后篇，并用其余卷补充日常关系。

方法上参考了以下角色扮演研究结论：

- [ArcANE](https://arxiv.org/abs/2606.05553)：角色应按篇章阶段描述心理与关系轨迹，而不是使用一份静态人设。
- [REVERIEMEM](https://arxiv.org/abs/2606.25632)：长篇角色扮演需要限制到角色本人视角，避免事实越权和风格扁平化。
- [Test-Time-Matching](https://arxiv.org/abs/2507.16799)：人格、记忆和语言风格应解耦组织。

这些资料只用于确定结构和校验方法；配置不收录长段原作文本。
